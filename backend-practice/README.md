# Backend. Учебные задания салона красоты

| Задание | Решение | Команда запуска |
| --- | --- | --- |
| 1 | [Класс записи и часы работы](appointments.py) | `python appointments.py` |
| 2 | [HTTP API категорий](categories_api.py) | `python -m uvicorn categories_api:app` |
| 3 | [Мастера в SQLite](masters_api.py) | `python -m uvicorn masters_api:app` |
| 4 | [Валидация и создание услуги](services_api.py) | `python -m uvicorn services_api:app` |

Запускайте команды из папки `backend-practice`. Для заданий 2–4 установите зависимости в виртуальное окружение из `requirements.txt`. Интерактивная документация API доступна по адресу `http://127.0.0.1:8000/docs`.

Демонстрационная запись в задании 1 хранится в памяти. Салон принимает запись с 08:00, последний возможный старт должен быть раньше закрытия в 20:00. Один мастер не может принять две записи на одно время.

В заданиях 3 и 4 файл `salon.sqlite3` создаётся при запуске. Для отдельной тестовой базы задайте путь через переменную `SALON_DATABASE`. Начальные мастера и категории добавляются один раз по идентификатору. `POST /services` создаёт услугу для существующей категории. Длительность передаётся в минутах.
